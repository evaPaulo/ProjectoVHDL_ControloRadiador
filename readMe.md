# ProjectoVHDL_ControloRadiador
Controlador digital inteligente e simulador de ambiente térmico em VHDL para FPGA Altera DE2-115.

Projecto original desenvolvido em 2023, na Unidade Curricular de Laboratório de Sistemas Digitais, na Universidade de Aveiro.

Projecto remasterizado em 2026, individualmente, com reescrita integral de Documentação Técnica e Republicação de Código VHDL Organizado.
